# Диагностика отсутствующих анимаций

Дата: 2026-10-07, Asia/Novosibirsk.

## Зафиксированная проблема

У владельца отсутствовали автоматические презентации и плавная прокрутка по ссылкам шапки. Иногда движение появлялось после загрузки, затем останавливалось. Другие сайты могли продолжать анимироваться.

В Windows были отключены системные анимации: `CLIENT_AREA_ANIMATION=False`, `MinAnimate=0`. Сайт после загрузки считывал `prefers-reduced-motion: reduce` и полностью останавливал презентацию. Ограничения действовали одновременно в MotionProvider, usePresentation, AnchorNavigation и нескольких CSS media queries. Изменения только одного слоя недостаточно.

Системная настройка — нормальное состояние, а не признак неисправности ПК. Проверять media query нужно именно в проблемной вкладке: ОС, профиль браузера и тестовая эмуляция могут различаться.

## Принятое поведение

По запросу владельца презентация работает по умолчанию независимо от системных эффектов. Кнопка Motion в шапке выключает/включает движение. Выбор сохраняется в `localStorage['nabil-motion']`; JavaScript и CSS используют общий режим `html[data-motion]`.

Это решение для данного сайта. В других проектах отдельно определить политику reduced-motion и доступный способ управления движением.

## Проверка в проблемной вкладке

URL вводить в адресную строку браузера. Для диагностики открыть инструменты разработчика клавишей F12, выбрать Console и выполнить JavaScript там, не в PowerShell:

```js
({
  systemReduced: matchMedia('(prefers-reduced-motion: reduce)').matches,
  siteMotion: document.documentElement.dataset.motion,
  visible: document.visibilityState,
  phase: document.querySelector('.rack-scene')?.dataset.phase,
  running: document.querySelector('.rack-scene')?.dataset.running,
  active: document.querySelector('.rack-scene')?.dataset.active,
  webgl: document.querySelector('.rack-scene')?.dataset.webgl
})
```

- `siteMotion: 'reduced'`: посетитель выбрал паузу; кнопка Motion возобновляет движение.
- Нет `siteMotion`: проверить ошибки Console, загрузку JS и гидрацию; после пересборки возможны устаревшие чанки.
- `siteMotion: 'full'`, но `running: 'false'`: проверить видимость вкладки, положение секции, готовность сцены и ручную паузу.
- `running: 'true'`, но движения нет: сравнить фазу через несколько секунд, кадры canvas и вычисленные CSS-анимации.

## Проверки регрессии

Проверять `reduce` и `no-preference`: изменения фаз, кадров 3D-сцены, положения пакетов и промежуточные координаты прокрутки, а также ручную паузу и сохранение выбора после перезагрузки.

Принудительный `no-preference` в чистом автоматизированном профиле не воспроизводит настройки браузера владельца. В этом случае именно он скрыл проблему в предыдущих проверках.

После исправления прошли 55 компонентных тестов, связанные браузерные проверки, сборка, lint и typecheck. Установленный Chrome при эмуляции `reduce` показал `systemReduced=true`, `siteMotion=full`, `running=true`; кадры canvas менялись, ошибок JavaScript не было. Установленный Firefox и реальная вкладка владельца напрямую не проверены.

Защищённая Vercel preview-ссылка, перенаправляющая на вход, — отдельная проблема доступа к деплою.
